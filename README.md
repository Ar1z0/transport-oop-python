# Модель городского транспорта Воронежа (Python)

Проект по ООП: моделирование транспортной сети города Воронеж.

## Основные сущности
- `Stop` — остановка
- `Route` — маршрут и время между остановками
- `Trip` — рейс с временем отправления
- `TransportType` — автобус, троллейбус, маршрутка
- `TransportSystem` — диспетчер, расчет интервалов и поиск путей (прямые и с 1 пересадкой)

## Запуск
```bash
python main.py
```
